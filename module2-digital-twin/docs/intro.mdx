# Module 2: The Digital Twin (Gazebo & Unity)

Welcome to Module 2 of the AI & Humanoid Robotics Course! This module focuses on creating comprehensive digital twin systems for humanoid robotics applications using both Gazebo for physics simulation and Unity for high-fidelity visualization.

## What You'll Learn

In this module, you will:

- Understand the fundamentals of digital twin technology in robotics
- Master Gazebo for physics-based simulation of humanoid robots
- Leverage Unity for high-fidelity visualization and human-robot interaction
- Simulate realistic sensors including LiDAR, cameras, and IMUs
- Validate simulation against reality to minimize the sim-to-real gap
- Implement complete sim-to-real transfer workflows

## Module Structure

This module is organized into five comprehensive chapters:

### [Chapter 1: Digital Twin Fundamentals](./module-2-digital-twin/chapter1-intro/digital-twins-fundamentals.mdx)
Learn the core concepts of digital twins, their importance in robotics, and how they enable simulation-to-reality transfer.

### [Chapter 2: Gazebo Simulation](./module-2-digital-twin/chapter2-gazebo/gazebo-setup.mdx)
Master Gazebo setup, physics engines, environment creation, and ROS 2 integration for humanoid robotics.

### [Chapter 3: Unity Visualization](./module-2-digital-twin/chapter3-unity/unity-setup.mdx)
Explore Unity setup, rendering pipelines, robot importing, and human-robot interaction simulation.

### [Chapter 4: Sensor Simulation](./module-2-digital-twin/chapter4-sensors/lidar-simulation.mdx)
Simulate realistic sensors including LiDAR, depth cameras, RGB cameras, IMUs, and ROS 2 data streams.

### [Chapter 5: Validation & Reality Gap](./module-2-digital-twin/chapter5-validation/sim-to-real-gap.mdx)
Validate simulation against reality, understand the sim-to-real gap, and implement complete case studies.

## Prerequisites

Before starting this module, you should have:

- Basic understanding of robotics concepts
- Familiarity with ROS/ROS 2 (covered in Module 1)
- Basic programming skills in Python and C++
- Understanding of 3D coordinate systems and transformations

## Getting Started

Begin with [Chapter 1: Digital Twin Fundamentals](./module-2-digital-twin/chapter1-intro/digital-twins-fundamentals.mdx) to understand the foundational concepts, then progress through each chapter to build comprehensive digital twin systems.

Each chapter includes practical examples, code samples, and exercises to reinforce your learning.

This module prepares you for sim-to-real transfer by:

- Explaining sim-to-real gap mitigation strategies
- Providing validation frameworks for comparing simulation to reality
- Demonstrating complete case studies of sim-to-real transfer
