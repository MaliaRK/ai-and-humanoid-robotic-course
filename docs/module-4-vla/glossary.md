     8→This document provides definitions for key terms used throughout the Vision-Language-Action (VLA) module documentation.
     9→
    10→### Action Head
    11→The final layer of a neural network in a robotic model that outputs the action to be taken by the robot.
    12→
    13→### Embedding
    14→A learned representation of a piece of data, such as a word or image, as a vector of numbers. This allows for comparison and analysis of these concepts in a mathematical space.
    15→
    16→### Grasp
    17→The act of a robot picking up an object. This can be done in various ways, depending on the object and the robot's end-effector.
    18→
    19→### Policy
    20→In the context of robotics, a policy is a strategy or function that maps a robot's state to an action. It's the "brain" that decides what the robot should do at any given moment.
    21→
    22→### Pose
    23→The position and orientation of an object or robot in 3D space. It is typically represented by a combination of a translation and a rotation.
    24→
    25→### Safety Envelope
    26→The defined space within which a robot can operate safely. Any operation outside this envelope is considered unsafe and should be prevented.
    27→
    28→### Token
    29→A discrete unit of information, such as a word or a subword, that is used as input to a language model. In the VLA module, actions can also be represented as tokens.
    30→
    31→### Trajectory
    32→A sequence of points in space that a robot's end-effector or body follows over time. It defines the path and timing of a robot's movement.
