# Noise Models for Simulation

Realistic noise modeling is crucial for reducing the sim-to-real gap in robotics applications. This chapter covers the principles of noise modeling, implementation techniques, and best practices for creating realistic noise characteristics in simulation environments.

## Understanding Noise in Robotics

### Types of Noise

Robotic systems are subject to various types of noise that affect their operation:

#### Sensor Noise
- **White Noise**: Random, uncorrelated noise across all frequencies
- **Pink Noise**: Noise with power density inversely proportional to frequency
- **Brownian Noise**: Cumulative random walk noise
- **Quantization Noise**: Discrete step noise from digital conversion

#### Process Noise
- **Motor Noise**: Variations in actuator performance
- **Mechanical Noise**: Vibrations, backlash, and friction variations
- **Environmental Noise**: External disturbances and interactions

#### Communication Noise
- **Packet Loss**: Lost data in networked systems
- **Latency Variations**: Jitter in communication timing
- **Data Corruption**: Errors in transmitted information

### Noise Characteristics

Noise can be characterized by several properties:

- **Mean**: Average value of the noise
- **Variance/Standard Deviation**: Spread of noise values
- **Distribution**: Statistical distribution of noise values
- **Correlation**: Relationship between noise at different times
- **Spectral Density**: Frequency content of the noise

### Noise Generation Techniques

#### Box-Muller Transform
For generating Gaussian random variables:

```python
def box_muller_gaussian(mean=0, std_dev=1, size=1000):
    """
    Generate Gaussian noise using Box-Muller transform
    """
    if size % 2 == 1:
        size += 1  # Box-Muller works in pairs

    u1 = np.random.uniform(0, 1, size//2)
    u2 = np.random.uniform(0, 1, size//2)

    z1 = np.sqrt(-2 * np.log(u1)) * np.cos(2 * np.pi * u2)
    z2 = np.sqrt(-2 * np.log(u1)) * np.sin(2 * np.pi * u2)

    gaussian_samples = np.concatenate([z1, z2])
    return mean + std_dev * gaussian_samples[:size]
```

#### Inverse Transform Sampling
For generating noise from any distribution:

```python
def inverse_transform_sampling(cdf_inverse, size=1000):

    Generate samples using inverse transform sampling
    """
    uniform_samples = np.random.uniform(0, 1, size)
    return cdf_inverse(uniform_samples)
```

```python
def lidar_distance_noise(true_distance, base_noise_std=0.01, distance_factor=0.001):
    """
    Model LiDAR noise that increases with distance

    # Noise increases with distance
    noise_std = base_noise_std + distance_factor * true_distance

def simulate_lidar_scan_with_noise(ground_truth_ranges, fov=270, resolution=1.0):

    Simulate a LiDAR scan with realistic noise

    for i, true_range in enumerate(ground_truth_ranges):
        if true_range > 0:  # Valid measurement
            noise = lidar_distance_noise(true_range)
            noisy_range = max(0.05, true_range + noise)  # Ensure minimum range
            noisy_ranges.append(noisy_range)
        else:
            noisy_ranges.append(true_range)  # Keep invalid measurements as-is

    return noisy_ranges
```

```python
def photon_shot_noise(signal_level, quantum_efficiency=0.5):
    """
    Model photon shot noise (Poisson distributed)
    """
    # For large signals, Poisson approaches Gaussian
    if signal_level > 10:
        return np.random.normal(0, np.sqrt(signal_level * quantum_efficiency))
    else:
        # Use Poisson for low light conditions
        return np.random.poisson(signal_level * quantum_efficiency) - signal_level * quantum_efficiency
```

### IMU Noise Models

IMU sensors have complex noise characteristics described by Allan Variance:

#### Gyroscope Noise Model
```python
class GyroscopeNoiseModel:
    def __init__(self,
                 white_noise=0.001,      # Angle random walk (rad/sqrt(s))
                 bias_instability=0.0001, # Bias instability (rad/s)
                 rate_random_walk=0.00001, # Rate random walk (rad/s^3/2)
                 quantization=0.0001):    # Quantization (rad)
        self.white_noise = white_noise
        self.bias_instability = bias_instability
        self.rate_random_walk = rate_random_walk
        self.quantization = quantization

        # Bias random walk
        self.bias_drift = 0.0

    def generate_noise(self, dt):
        """
        Generate gyroscope noise for time step dt
        """
        # White noise (high frequency)
        white_noise = np.random.normal(0, self.white_noise / np.sqrt(dt))

        # Bias instability (random walk of bias)
        self.bias_drift += np.random.normal(0, self.bias_instability * np.sqrt(dt))

        # Rate random walk
        rate_walk = np.random.normal(0, self.rate_random_walk * np.sqrt(dt))

        # Quantization noise
        quantization_noise = np.random.uniform(-self.quantization/2, self.quantization/2)

        return white_noise + self.bias_drift + rate_walk + quantization_noise
```

#### Accelerometer Noise Model
```python
class AccelerometerNoiseModel:
    def __init__(self,
                 white_noise=0.01,      # Velocity random walk (m/s/sqrt(s))
                 bias_instability=0.001, # Bias instability (m/s^2)
                 rate_random_walk=0.0001, # Rate random walk (m/s^3/2)
                 gravity_variation=0.005): # Gravity model error (m/s^2)
        self.white_noise = white_noise
        self.bias_instability = bias_instability
        self.rate_random_walk = rate_random_walk
        self.gravity_variation = gravity_variation

        self.bias_drift = 0.0

    def generate_noise(self, dt):
        """
        Generate accelerometer noise for time step dt
        """
        white_noise = np.random.normal(0, self.white_noise / np.sqrt(dt))
        self.bias_drift += np.random.normal(0, self.bias_instability * np.sqrt(dt))
        rate_walk = np.random.normal(0, self.rate_random_walk * np.sqrt(dt))

        return white_noise + self.bias_drift + rate_walk
```

## Temporal Noise Models

### Random Walk Processes

Model slowly varying parameters:

```python
class RandomWalkProcess:
    def __init__(self, initial_value=0, step_std=0.001):
        self.value = initial_value
        self.step_std = step_std

    def step(self, dt=1.0):
        """
        Update the random walk process
        """
        self.value += np.random.normal(0, self.step_std * np.sqrt(dt))
        return self.value

# Example: Slowly varying sensor bias
sensor_bias_rw = RandomWalkProcess(initial_value=0, step_std=0.0001)
```

### Autoregressive Models

Model noise with temporal correlation:

```python
class AutoregressiveNoise:
    def __init__(self, coefficients=[0.9], noise_std=0.01):
        """
        AR(1) model: x[n] = a*x[n-1] + noise
        """
        self.coefficients = coefficients
        self.noise_std = noise_std
        self.history = [0] * len(coefficients)

    def generate_next(self):
        """
        Generate next value in the autoregressive process
        """
        # AR model: x[n] = sum(a_i * x[n-i]) + noise
        output = 0
        for i, coeff in enumerate(self.coefficients):
            output += coeff * self.history[i]

        noise = np.random.normal(0, self.noise_std)
        output += noise

        # Update history
        self.history = [output] + self.history[:-1]

        return output
```

### Ornstein-Uhlenbeck Process

Model mean-reverting noise:

```python
class OrnsteinUhlenbeckProcess:
    def __init__(self, theta=0.15, mu=0, sigma=0.2):
        """
        theta: rate of reversion to mean
        mu: long-term mean
        sigma: volatility
        """
        self.theta = theta
        self.mu = mu
        self.sigma = sigma
        self.current_value = mu

    def step(self, dt=1.0):
        """
        Step the OU process forward in time
        """
        drift = self.theta * (self.mu - self.current_value) * dt
        diffusion = self.sigma * np.sqrt(dt) * np.random.normal()

        self.current_value += drift + diffusion
        return self.current_value
```

### Unity Noise Implementation

Adding realistic noise in Unity:

```csharp
using UnityEngine;
using System.Collections.Generic;

public class SensorNoiseModel : MonoBehaviour
{
    [Header("Noise Configuration")]
    public NoiseType noiseType = NoiseType.Gaussian;
    public float noiseStdDev = 0.01f;
    public float bias = 0.0f;
    public float biasDriftRate = 0.001f;

    private float currentBias = 0.0f;
    private float timeAccumulator = 0.0f;

    public enum NoiseType
    {
        Gaussian,
        Uniform,
        RandomWalk,
        Quantization
    }

    void Update()
    {
        timeAccumulator += Time.deltaTime;

        // Update slowly varying bias
        if (timeAccumulator > 1.0f) // Update bias every second
        {
            currentBias += RandomGaussian(0, biasDriftRate);
            timeAccumulator = 0;
        }
    }

    public float AddNoise(float trueValue)
    {
        float noise = 0;

        switch (noiseType)
        {
            case NoiseType.Gaussian:
                noise = RandomGaussian(0, noiseStdDev);
                break;
            case NoiseType.Uniform:
                noise = Random.Range(-noiseStdDev, noiseStdDev);
                break;
            case NoiseType.RandomWalk:
                noise = RandomGaussian(0, noiseStdDev * Mathf.Sqrt(Time.deltaTime));
                break;
            case NoiseType.Quantization:
                noise = QuantizationNoise(trueValue, noiseStdDev);
                break;
        }

        return trueValue + noise + bias + currentBias;
    }

    float RandomGaussian(float mean, float stdDev)
    {
        float u1 = Random.value; // Uniform(0,1] random doubles
        float u2 = Random.value;
        float randStdNormal = Mathf.Sqrt(-2.0f * Mathf.Log(u1)) * Mathf.Sin(2.0f * Mathf.PI * u2); // Random normal(0,1)
        return mean + stdDev * randStdNormal; // Random normal(mean,stdDev^2)
    }

    float QuantizationNoise(float value, float resolution)
    {
        float quantized = Mathf.Round(value / resolution) * resolution;
        return quantized - value;
    }
}
```

## Validation of Noise Models

### Statistical Validation

Validate that generated noise matches expected characteristics:

```python
from scipy import stats
import matplotlib.pyplot as plt

def validate_noise_characteristics(noise_samples, expected_mean=0, expected_std=1, alpha=0.05):
    """
    Validate noise characteristics using statistical tests
    """
    results = {}

    # Test mean
    sample_mean = np.mean(noise_samples)
    t_stat, p_value = stats.ttest_1samp(noise_samples, expected_mean)
    results['mean_test'] = {
        'sample_mean': sample_mean,
        'p_value': p_value,
        'significant': p_value < alpha
    }

    # Test variance
    sample_std = np.std(noise_samples)
    chi2_stat = (len(noise_samples) - 1) * sample_std**2 / expected_std**2
    p_value_var = 1 - stats.chi2.cdf(chi2_stat, len(noise_samples) - 1)
    results['variance_test'] = {
        'sample_std': sample_std,
        'p_value': p_value_var,
        'significant': p_value_var < alpha
    }

    # Normality test (Shapiro-Wilk for normality)
    if len(noise_samples) <= 5000:  # Shapiro-Wilk is limited to ~5000 samples
        _, p_value_normal = stats.shapiro(noise_samples)
        results['normality_test'] = {
            'p_value': p_value_normal,
            'normal': p_value_normal > alpha
        }

    return results

# Example validation
noise_samples = np.random.normal(0, 0.01, 1000)
validation_results = validate_noise_characteristics(noise_samples, expected_mean=0, expected_std=0.01)
print("Noise Validation Results:")
for test, result in validation_results.items():
    print(f"  {test}: {result}")
```

## Advanced Noise Modeling

### Colored Noise Generation

Generate noise with specific spectral characteristics:

```python
def generate_colored_noise(beta, size, fmin=0, fmax=0.5):
    """
    Generate colored noise with power spectral density S(f) ~ f^beta
    beta = 0: white noise
    beta = -1: pink noise
    beta = -2: brown noise
    """
    # Generate frequency array
    frequencies = np.fft.fftfreq(size)

    # Generate complex noise
    real_part = np.random.normal(0, 1, size//2 + 1)
    imag_part = np.random.normal(0, 1, size//2 + 1)
    complex_noise = real_part + 1j * imag_part

    # Apply frequency weighting
    weights = np.zeros_like(frequencies[:size//2 + 1])
    for i, f in enumerate(frequencies[:size//2 + 1]):
        if fmin <= abs(f) <= fmax and f != 0:
            weights[i] = abs(f) ** (beta/2)
        elif f == 0:
            weights[i] = 1  # DC component

    weighted_noise = complex_noise * weights

    # Inverse FFT to get time domain noise
    colored_noise = np.fft.irfft(weighted_noise, n=size)

    return colored_noise
```

```python
def compute_allan_variance(data, rate):
    """
    Compute Allan variance of data
    """
    taus = []
    adevs = []

    max_tau = len(data) // 2

    for tau in [2**i for i in range(1, int(np.log2(max_tau)) + 1)]:
        if tau >= len(data):
            continue

        # Average data in bins of size tau
        n_bins = len(data) // tau
        binned_data = [np.mean(data[i*tau:(i+1)*tau]) for i in range(n_bins)]

        # Compute differences
        diffs = np.diff(binned_data)

        # Allan deviation
        adev = np.sqrt(0.5 * np.mean(diffs**2))

        taus.append(tau / rate)  # Convert to seconds
        adevs.append(adev)

    return np.array(taus), np.array(adevs)
```

## Best Practices

### Noise Model Selection

Choose appropriate noise models based on:

- **Sensor Type**: Different sensors have different noise characteristics
- **Application Requirements**: Critical applications need more accurate models
- **Computational Constraints**: Balance accuracy with performance
- **Available Data**: Use real data to calibrate models when possible

### Validation Protocol

Always validate noise models:

1. **Statistical Tests**: Verify distribution parameters
2. **Temporal Characteristics**: Check correlation and spectral properties
3. **Physical Plausibility**: Ensure noise is realistic
4. **Impact Assessment**: Test how noise affects system performance

Tune noise parameters systematically:

## Common Pitfalls

### Overfitting Noise Models

Avoid overfitting to specific datasets:

- Use cross-validation when fitting models
- Validate on multiple datasets
- Consider generalization to different conditions

### Ignoring Correlations

Don't assume all noise is independent:

- Consider spatial correlations in sensor arrays
- Account for temporal correlations
- Model coupled noise sources appropriately

### Computational Complexity

Balance model accuracy with computational cost:

- Use efficient algorithms for real-time applications
- Consider approximate methods when exact solutions are too slow
- Profile noise generation to identify bottlenecks
