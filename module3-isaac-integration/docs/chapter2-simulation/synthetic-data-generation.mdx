# Synthetic Data Generation

Synthetic data generation is a cornerstone of modern robotics development, allowing for the creation of large, diverse datasets without the constraints of real-world data collection. Isaac Sim provides powerful tools for generating photorealistic synthetic data that can be used to train perception, navigation, and control systems for humanoid robots.

## Isaac Sim Data Generation Tools

### Replicator Framework
- Procedural scene generation
- Domain randomization
- Multi-camera setups
- Custom annotators and sensors

### Example: Basic Replicator Setup
```python
# Example: Setting up synthetic data generation with Replicator
import omni.replicator.core as rep

# Initialize Replicator
rep = rep.get_omni_replicator()

# Create a simple scene with a humanoid robot
with rep.new_layer():
    # Add ground plane
    ground = rep.create.plane(semantics=[("class", "ground")])

    # Add humanoid robot
    robot = rep.create.from_usd(
        usd_path="path/to/humanoid.usd",
        semantics=[("class", "humanoid")]
    )

    # Add camera
    camera = rep.create.camera()

    # Position camera to view the robot
    with camera:
        rep.modify.pose(
            position=rep.distribution.uniform((-2, -2, 1), (2, 2, 3)),
            rotation=rep.distribution.uniform((-15, -180, -15), (15, 180, 15))
        )

# Annotators for different data types
with rep.trigger.on_frame(num_frames=100):
    # RGB annotator
    rep.annotate.camera("rgb", camera)

    # Depth annotator
    rep.annotate.camera("distance_to_image_plane", camera)

    # Semantic segmentation
    rep.annotate.camera("semantic_segmentation", camera)

    # Instance segmentation
    rep.annotate.camera("instance_segmentation", camera)

# Run the data generation
rep.run()
```

## Domain Randomization

### Purpose
Domain randomization helps bridge the sim-to-real gap by:
- Varying environmental conditions
- Adding visual diversity
- Improving model robustness
- Reducing overfitting to specific conditions

### Randomization Techniques
- **Lighting**: Randomize position, color, intensity
- **Materials**: Randomize textures, colors, reflectance
- **Geometry**: Randomize object placement, scale
- **Camera**: Randomize position, orientation, intrinsics
- **Weather**: Randomize fog, rain, snow effects

### Example: Domain Randomization
```python
# Example: Domain randomization for humanoid perception
import omni.replicator.core as rep

def randomize_lighting():
    """Randomize lighting conditions"""
    lights = rep.get.prims(path_pattern="/World/Light/*")

    with lights:
        rep.modify.attribute("inputs:intensity",
                           rep.distribution.uniform(100, 10000))
        rep.modify.attribute("inputs:color",
                           rep.distribution.uniform((0.5, 0.5, 0.5), (1, 1, 1)))

def randomize_materials():
    """Randomize material properties"""
    materials = rep.get.prims(path_pattern="/World/Materials/*")

    with materials:
        rep.randomizer.color_texture(
            color_texture=rep.distribution.choice([
                "path/to/texture1.png",
                "path/to/texture2.png",
                "path/to/texture3.png"
            ])
        )

def randomize_robot_appearance():
    """Randomize humanoid robot appearance"""
    robot_materials = rep.get.prims(path_pattern="/World/Humanoid/Materials/*")

    with robot_materials:
        rep.modify.attribute("inputs:diffuse_texture:file",
                           rep.distribution.choice([
                               "path/to/robot_texture1.png",
                               "path/to/robot_texture2.png"
                           ]))
```
