# ROS 2 Integration for Perception

## Introduction

The integration of Isaac ROS perception modules with the ROS 2 ecosystem enables humanoid robots to leverage GPU-accelerated perception capabilities within the standard ROS 2 framework. This integration provides access to optimized perception algorithms while maintaining compatibility with the extensive ROS 2 tooling and package ecosystem.

## Architecture Overview

### Integration Layers
```
ROS 2 Application Layer
├── Standard ROS 2 Nodes
├── Isaac ROS Perception Nodes
└── Isaac ROS GEMs (GPU-accelerated)
    └── CUDA/TensorRT Kernels

Communication Layer
├── Standard ROS 2 Messages
├── Isaac ROS Messages
└── Custom Message Types

Infrastructure Layer
├── ROS 2 Middleware (DDS)
├── Isaac ROS Common
└── GPU Runtime
```

### Key Components
- **Isaac ROS Bridge**: Translates between Isaac and ROS 2 interfaces
- **Message Adapters**: Convert between Isaac and ROS 2 message formats
- **Parameter Systems**: Unified parameter management
- **Lifecycle Management**: ROS 2 node lifecycle integration

## Message Types and Conversions

### Standard ROS 2 Messages
- `sensor_msgs/Image`: Camera images
- `sensor_msgs/CompressedImage`: Compressed camera images
- `sensor_msgs/PointCloud2`: Point cloud data
- `geometry_msgs/PointStamped`: 3D point with timestamp
- `geometry_msgs/PoseStamped`: 3D pose with timestamp

### Isaac ROS Specific Messages
- `isaac_ros_messages/FeatureArray`: Feature detection results
- `isaac_ros_messages/TrackedFeatureArray`: Tracked features with motion
- `isaac_ros_messages/EstimatedTwist`: Estimated velocity from visual odometry
- `isaac_ros_messages/FeatureMatchArray`: Feature matching results

### Message Conversion Example
```python
# Example: Message conversion between Isaac and ROS 2
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Image
from geometry_msgs.msg import PointStamped
from std_msgs.msg import Header
import numpy as np

class IsaacROSMessageConverter(Node):
    def __init__(self):
        super().__init__('isaac_ros_message_converter')

        # Publishers and subscribers
        self.image_sub = self.create_subscription(
            Image, '/camera/image_raw', self.image_callback, 10
        )
        self.feature_pub = self.create_publisher(
            PointStamped, '/features/point', 10
        )

    def image_callback(self, ros_image_msg):
        """Convert ROS 2 Image to Isaac format and process"""
        # Convert ROS Image to numpy array
        image_array = self.ros_image_to_numpy(ros_image_msg)

        # Process with Isaac ROS GEMs (conceptual)
        features = self.process_with_isaac_gems(image_array)

        # Convert Isaac features back to ROS 2 messages
        ros_features = self.isaac_features_to_ros(features)

        # Publish ROS 2 messages
        for feature in ros_features:
            self.feature_pub.publish(feature)

    def ros_image_to_numpy(self, ros_image_msg):
        """Convert ROS 2 Image message to numpy array"""
        # Determine image format
        if ros_image_msg.encoding == 'rgb8':
            dtype = np.uint8
            channels = 3
        elif ros_image_msg.encoding == 'mono8':
            dtype = np.uint8
            channels = 1
        elif ros_image_msg.encoding == '32FC1':
            dtype = np.float32
            channels = 1

        # Reshape image data
        image_array = np.frombuffer(ros_image_msg.data, dtype=dtype)
        image_array = image_array.reshape(
            ros_image_msg.height, ros_image_msg.width, channels
        )

        return image_array

    def isaac_features_to_ros(self, isaac_features):
        """Convert Isaac features to ROS 2 PointStamped messages"""
        ros_features = []
        for feature in isaac_features:
            point_msg = PointStamped()
            point_msg.header = Header()
            point_msg.header.stamp = self.get_clock().now().to_msg()
            point_msg.header.frame_id = "camera_link"

            # Set point coordinates
            point_msg.point.x = feature.x
            point_msg.point.y = feature.y
            point_msg.point.z = feature.z

            ros_features.append(point_msg)

        return ros_features
```

## TF (Transform) Integration

### Coordinate Frame Management
```python
# Example: TF integration for perception
from tf2_ros import TransformBroadcaster, Buffer, TransformListener
from geometry_msgs.msg import TransformStamped

class IsaacROSTFManager:
    def __init__(self, node):
        self.node = node
        self.tf_broadcaster = TransformBroadcaster(node)
        self.tf_buffer = Buffer()
        self.tf_listener = TransformListener(self.tf_buffer, node)

    def publish_camera_transforms(self):
        """Publish camera-related transforms"""
        transforms = []

        # Camera optical frame (ROS standard)
        t = TransformStamped()
        t.header.stamp = self.node.get_clock().now().to_msg()
        t.header.frame_id = "camera_link"
        t.child_frame_id = "camera_optical_frame"

        # Rotate from camera coordinate system to optical coordinate system
        # (X right, Y down, Z forward) -> (X right, Y down, Z forward)
        t.transform.translation.x = 0.0
        t.transform.translation.y = 0.0
        t.transform.translation.z = 0.0
        t.transform.rotation.x = -0.5
        t.transform.rotation.y = 0.5
        t.transform.rotation.z = -0.5
        t.transform.rotation.w = 0.5

        transforms.append(t)

        # Publish all transforms
        for transform in transforms:
            self.tf_broadcaster.sendTransform(transform)

    def lookup_camera_to_base_transform(self, timestamp):
        """Lookup transform from camera to robot base"""
        try:
            transform = self.tf_buffer.lookup_transform(
                "base_link",
                "camera_link",
                timestamp,
                timeout=rclpy.duration.Duration(seconds=1.0)
            )
            return transform
        except Exception as e:
            self.node.get_logger().warn(f"Could not lookup transform: {e}")
            return None
```

## Performance Considerations

### Message Rate Optimization
- **Throttling**: Use message filters to reduce processing rate
- **Queuing**: Optimize publisher/subscriber queue sizes
- **Synchronization**: Properly synchronize stereo and multi-sensor data
- **Compression**: Use image compression for high-bandwidth data

### Memory Management
- **Zero-Copy**: Use zero-copy message passing when possible
- **Memory Pools**: Pre-allocate message buffers
- **Shared Memory**: Use shared memory for large data (point clouds)
- **GPU Memory**: Efficient GPU-CPU memory transfers

### Real-Time Considerations
- **Deterministic Processing**: Ensure predictable processing time
- **Priority Scheduling**: Set appropriate thread priorities
- **Resource Isolation**: Isolate perception from other processes
- **Jitter Minimization**: Minimize timing variations
